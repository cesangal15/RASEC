Esta pantalla es solo para el rol admin. Tu sesión no tiene permiso para entrar aquí.

Edita las tablas de catálogo directamente contra la base (solo admin): elige la tabla y se carga sola (las de Registros piden un rango de fechas y Consultar). Las columnas en gris no se editan. Se maneja como Excel (flechas, Ctrl+flechas, Shift para marcar, Ctrl+C/V/D/Z); pulsa ⌨ para ver todos los atajos y usa el clic derecho para insertar, duplicar o eliminar filas. Cada guardado se valida en el servidor y es todo o nada.
